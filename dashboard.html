Model provider

Local keeps every question on this machine and works with the network down. Hosted is faster and smarter, and sends the conversation off the robot. Keys are written to lancer_secrets.json, which is untracked and never read back into this page.
Local and Gemini are offered the skill schemas and can decide to call one mid-answer. Anthropic is skills by rule only — a limit of this app, not of the provider: its tool protocol is not wired up yet. Rule-driven skills — weather, the date, document lookup — run on every provider regardless, because those are chosen here and injected before the model sees anything.
